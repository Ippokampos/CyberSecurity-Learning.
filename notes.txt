Κατηγορία Εργαλείο / Εντολή Τι πετύχαμε με αυτήν
Προετοιμασία pkg update && pkg upgrade Ενημερώσαμε το Termux για να δουλεύει σωστά.
Αναγνώριση (Web) curl -I akrogialios.gr Είδαμε τον τύπο του server και την απόκριση του site.
Έλεγχος Δικτύου nmap -F akrogialios.gr Βρήκαμε τις ανοιχτές "πόρτες" (Ports), π.χ. 21, 80, 3306.
Βαθιά Διάγνωση nmap -sV -p 21,3306,80 akrogialios.gr Ανακαλύψαμε τις εκδόσεις των προγραμμάτων (MariaDB, ProFTPD).
Πληροφορίες Domain whois akrogialios.gr Μάθαμε τον πάροχο (Buildhosting) και τους Name Servers.
Διαχείριση Αρχείων ls και cd [φάκελος] Πλοηγηθήκαμε μέσα στα αρχεία του κινητού σου.
Σύνδεση Portfolio git push ή git commit Ανεβάσαμε

Τα Αρχεία που δημιούργησες (Το Portfolio σου)
​Στο Repository σου στο GitHub, έχεις πλέον τα εξής αρχεία:
​site_report.txt: Η πρώτη εικόνα του site.
​final_audit.txt: Η λίστα με όλες τις ανοιχτές θύρες.
​service_scan.txt: Οι εκδόσεις MariaDB και ProFTPD.
​vulnerability_analysis.txt: Τα CVE (τρύπες) που βρήκες στο Google.
​whois_report.txt: Τα στοιχεία ιδιοκτησίας και λήξης του domain.
​💡 Architect Tip:
​Κράτα αυτόν τον πίνακα σε ένα "Note" στο κινητό σου ή κάνε τον screenshot. Είναι η απόδειξη της προόδου σου από το "χάθηκα" στο "ελέγχω την ασφάλεια ενός server".
​Θέλεις να προσθέσουμε στον πίνακα και την εντολή για την εγκατάσταση του SQLmap, ή θέλεις να κάνουμε μια επανάληψη σε κάποια από αυτές τις εντολές;
